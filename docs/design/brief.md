# Xiahua DISK 设计任务

产品是基于 MangoDisk 的跨平台桌面磁盘分析与清理工具，新品牌准确写作 Xiahua DISK。目标是形成一个可以实际发布的个人品牌分支，不改变文件扫描、清理规则和删除前校验。用户是普通电脑使用者、开发者及使用本地 AI 模型的人。他们在磁盘空间紧张时打开应用，希望迅速找到空间占用，理解每个项目的意义，在确认范围后执行清理。设计应传达掌控感、清晰度和可靠性；不能把危险操作包装成游戏奖励，也不能用虚构的清理容量刺激用户操作。

本轮先探索桌面应用主界面，统一画布为 1440×900 像素，自适应较小视口。产物是纯 HTML/CSS 单文件；少量原生 JavaScript 可以演示导航、主题切换和筛选。每个方向只写自己的文件，不查看其他方向。实际生产项目是 Vue 3 + Tauri 2。原生清理逻辑由 Rust 负责，浏览器设计稿不能假装已经访问本机磁盘。所有示意数据应明确写「界面预览 · 未连接本机磁盘」，容量统一用「—」或「等待扫描」，不能编造磁盘利用率、文件数量或已回收空间。

所有版本必须呈现同样的内容：Xiahua DISK 品牌；左侧导航按存储、安全、系统分组，含深度清理、大文件、重复文件、空间分析、隐私清理、应用卸载、启动项、系统维护、历史、设置；主工作区标题「深度清理」；说明「查看可清理内容，再决定如何处理」；范围选择「选择扫描位置」；主要按钮「开始扫描」；状态「尚未扫描」；可清理类别「系统与应用缓存」「浏览器缓存」「开发项目产物」「本地 AI 模型」，各项有短用途说明；模型默认不选择的提示；底部清理区域显示「未选择项目」，清理按钮禁用。设计需要可见的信息差异，例如明确的范围、风险、默认选择状态，不靠装饰图标堆砌。

新品牌尚无用户提供的 Logo 或色板，允许提出 X 字母/字标为中心的抽象品牌方案。以排版为主，不需要照片；磁盘工具的内容不会因没有摄影受损。不得使用旧芒果 Logo 冒充新品牌。第三方产品的名字不作为装饰出现在界面上，因此无需第三方 logo 墙。避免紫色渐变、深蓝霓虹、每行圆角卡片加彩色左边框、虚构统计数据以及夸张的清理承诺。使用单一强调色和明确的分隔层级；允许方向之间在温度、密度和排版上形成明显差异。

中文正文需易读；英文品牌可采用有特点的 display 字体。图标只服务操作识别。所有可点击元素有明确焦点状态。清理按钮在无选择时不可点击。只读预览中的按钮不得声称真实扫描成功，可更新为「此为设计预览，请在桌面应用扫描」。输出文件开头写英文 assumptions 与设计理由注释。交付前检查窗口尺寸、溢出、文字对比度与交互。每个设计给出一句设计取舍及可迁移到 Vue 的颜色/布局建议。
