Xiahua DISK is an independent fork of MangoDisk, with separate application identity and installation data.

- Updated product name, application icons and project links.
- Original scan, protected-path and cleanup-confirmation safeguards retained.
- Feedback goes to this repository's GitHub Issues.
- Updates are downloaded manually from this repository's Releases.
- Optional AI uses a user-configured provider; upstream free AI is not provisioned.

The packages are not Apple notarized or Windows Authenticode signed. Choose the package for your operating system and architecture. Browser design previews cannot scan or clean local disks.
